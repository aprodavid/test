# 내리숲 AI 질문 연구소 🌿

초등학생용 **AI 질문 연구소** 단일 페이지 웹앱입니다. 학생이 떠올린 질문을
6가지 유형으로 분류하고 3단계로 정제하며, 질문 도감·놀이터(가챠)·지혜 숲까지
제공합니다. 프레임워크·빌드도구·백엔드 없이 **바닐라 HTML/CSS/JS**로 동작하고,
저장은 브라우저 `localStorage`만 사용합니다.

## 📁 프로젝트 구조

```
index.html   ← 마크업 (헤더 · 4개 탭 · 모달 · 푸터)
style.css    ← 전체 스타일 (원본 <style> 블록 그대로 이관)
app.js       ← 데이터 + 로직 (원본 <script> 블록 이관 + 아래 변경사항 반영)
README.md    ← 이 문서
```

원본은 단일 HTML 파일이었고, 유지보수를 위해 위 3개 파일로 분리했습니다.
동작은 원본과 100% 동일합니다.

## 🚀 실행 방법 (로컬)

이 앱은 순수 정적 파일이라 별도 설치가 필요 없습니다.

- **가장 간단한 방법:** `index.html`을 브라우저로 그냥 열면 됩니다.
- **권장(로컬 서버):** 일부 브라우저의 보안 정책 때문에 로컬 서버로 여는 것이
  가장 안정적입니다.
  ```bash
  # 셋 중 아무거나
  python3 -m http.server 8000
  npx serve .
  ```
  그런 다음 브라우저에서 `http://localhost:8000` 접속.

## 🔑 Gemini API 키 설정법 (실시간 AI 분석 켜기)

키가 없어도 앱은 **오프라인 간이 분석기**로 정상 동작합니다. 실시간 AI 분석을
켜려면 무료 키를 발급받아 넣으세요.

1. [Google AI Studio](https://aistudio.google.com/apikey)에 접속해 **무료 API
   키**를 발급받습니다.
2. `app.js` 맨 위의 **[선생님 전용 설정 구역]** 에서 다음 줄을 찾습니다.
   ```js
   const GEMINI_API_KEY = "";
   ```
3. 따옴표 안에 발급받은 키를 붙여넣고 저장합니다.
   ```js
   const GEMINI_API_KEY = "여기에_발급받은_키_붙여넣기";
   ```
4. 저장 후 새로고침하면 실시간 AI 분석이 켜집니다.

> ⚠️ **보안 주의:** 이 앱은 순수 프론트엔드라서 키가 브라우저 소스에 그대로
> 노출됩니다. 반드시 **무료 등급 키**만 사용하고, 키가 들어간 파일을 학급 외부에
> 공개 저장소로 배포하지 마세요. (공개 배포가 필요하면 키를 비운 `""` 상태로
> 배포해 오프라인 분석기로만 동작시키는 것을 권장합니다.)

### AI 모델 교체

`app.js`의 `GEMINI_MODEL` 한 줄로 모델을 바꿀 수 있습니다.

```js
const GEMINI_MODEL = "gemini-2.5-flash-lite"; // 기본값 (하루 약 1,000회)
// "gemini-2.5-flash" 로 바꾸면 답변 품질이 조금 더 높아집니다 (하루 약 250회)
```

무료 한도는 구글 정책에 따라 달라질 수 있으니 정확한 수치는 AI Studio에서
확인하세요.

## ☁️ 배포 (Vercel 정적 호스팅)

빌드 과정이 없으므로 그대로 정적 배포하면 됩니다.

1. 이 저장소를 Vercel에 연결합니다.
2. **Framework Preset: Other**, **Build Command: (비움)**,
   **Output Directory: `.`(루트)** 로 두면 됩니다.
3. 배포 후 `index.html`이 그대로 서비스됩니다.

> 배포 시 주의: 공개 URL에는 API 키를 넣지 마세요(위 보안 주의 참고). 외부
> 의존성은 Google Fonts 링크와 Gemini API 호출뿐이며, 네트워크가 막히면 글꼴은
> 기본 글꼴로, AI 분석은 오프라인 간이 분석기로 자동 대체됩니다.

## ✨ 기능

| 탭 | 설명 |
|----|------|
| 질문 연구실 | 학년군 선택 → 질문 입력 → 6유형 분류 + 3단계 정제 + 응원 메시지 |
| 질문 도감 | 6가지 질문 유형(관찰·공감·해석·표현·판단·실천) 설명서 |
| 질문 놀이터 | 학년군별 8문항 퀴즈, 정답 시 아이템 가챠, 보물 주머니 |
| 지혜 숲 | 저장한 질문 목록, 2개 이상 선택 시 핵심 문장 일반화, 성장 지수·정원 |

**AI 로직(이원 구조):** 키가 있으면 Gemini API 직접 호출(지수 백오프 3회 재시도),
키가 비었거나 네트워크 실패 시 규칙 기반 간이 분석기(`simulateFallback`)로 자동
전환됩니다.

## 💾 데이터 저장

모든 데이터는 브라우저 `localStorage`에만 저장됩니다(서버·DB·계정 없음).

- `naerisoop_saved_questions` — 저장한 질문 숲
- `naerisoop_playground_inventory` — 놀이터 보물 주머니·점수
